Конфиденциальность

Repair Station Map · редакция 06.10.2026

Сервис хранит только данные, необходимые для карты, профиля, модерации и защиты от спама.

Что хранится

Случайный идентификатор профиля/устройства, тип устройства, ОС и браузер; имя профиля, история полезных действий, репутация, достижения и награды; отправленные фотографии и предложенные координаты станций.

Passkey / Face ID / Touch ID

Биометрические данные сайт не получает и не хранит. Face ID/Touch ID обрабатываются операционной системой. На сервере хранится только публичная часть Passkey и техническая информация, необходимая для восстановления профиля.

Защита от спама

Для ограничения массовых отправок IP-адрес кратковременно преобразуется в односторонний SHA-256 хэш. Такие записи предназначены только для антиспама и удаляются примерно через 48 часов.

Геолокация

Текущее местоположение запрашивается браузером только после разрешения пользователя и само по себе не сохраняется как профильная история. Координаты сохраняются, когда пользователь сознательно предлагает новую станцию или создаёт связанную с картой запись.

Чего сайт не получает

IMEI, MAC-адрес, серийный номер телефона/компьютера, отпечаток пальца, скан лица или пароль Passkey.

Фотографии

Фотографии проходят модерацию. До одобрения они не являются публичной частью галереи станции.
