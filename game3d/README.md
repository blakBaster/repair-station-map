# Warsaw Runner 3D

Полностью отдельный 3D-прототип игры. Основной Repair Station Map не изменяется.

## Что есть
- настоящее 3D-пространство;
- вид от третьего лица;
- 3D-персонаж;
- WASD;
- Shift — бег;
- камера мышью;
- объёмные дома, дороги, тротуары и деревья;
- реальные Repair Station подгружаются только на чтение;
- E — взаимодействие со станцией.

## Запуск
Открой папку через локальный HTTP-сервер и зайди на game3d/index.html.
